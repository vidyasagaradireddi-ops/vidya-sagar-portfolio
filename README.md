# Adireddi Vidya Sagar — Multi-page CSE / AI & ML Portfolio

Responsive multi-page React portfolio using Vite, React Router, Tailwind CSS and Motion. Design: Apple-inspired white/silver/light-blue glassmorphism, pointer-reactive 3D portrait tilt, animated orbit rings and one interactive 3D ghost companion.

The ghost now chases the pointer across the viewport with spring easing and a safe offset, floats and rotates, and reacts to clicks.

## Pages
Home · About · Education · Skills · Projects · Individual project detail pages · Interests · Contact

## Run locally
1. Install Node.js LTS.
2. Extract this ZIP and open a terminal in the project folder.
3. Run `npm install`.
4. Run `npm run dev` and open the Vite local URL.

## Production build
Run `npm run build`. Output is created in `dist/`.
